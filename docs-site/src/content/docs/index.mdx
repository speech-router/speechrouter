## Thirty seconds to a transcript

```bash
curl -s https://api.speechrouter.ai/v1/audio/transcriptions \
  -H "Authorization: Bearer $SPEECHROUTER_API_KEY" \
  -F model=deepgram/nova-3 \
  -F file=@meeting.wav
```

Change `deepgram/nova-3` to `soniox/stt-rt-v5`, `openai/gpt-4o-transcribe`, or any
of the [live models](/providers/) — nothing else in your code moves.
